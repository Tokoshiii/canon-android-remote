# Appareil v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. TDD for all pure logic.

**Goal:** Bluetooth discovery fix, Appareil tab v2 (M3 stepped sliders, mode/AF-MF awareness, Basique/Avancé, timer mini-wheel), developer mode, new settings.
**Architecture:** Camera-side knowledge (mode dial 0xD105, focus mode 0xD108, locks, slider models) in pure `:core` (JVM-tested); preferences and timer state machine as pure classes in `:app` (JVM tests run in CI, verifiable in a scratch JVM project); Compose UI in `:app` verified by CI.
**Spec:** `docs/superpowers/specs/2026-11-20-appareil-v2-design.md` (mockups: https://claude.ai/artifact/ULxQ1oPefZF8C187TTPqyx — style C "Curseur" and "Retardateur-Roue").

## Global Constraints
- `:core` pure JVM; local tests `./gradlew -PskipApp=true test`; `:app` verified by CI only; named args for Compose/Material3.
- UI texts in French; Material 3 dynamic colors; minSdk 31.
- Sliders: Material3 `Slider` with `steps`; one notch per value in `available`; label follows finger; `set` sent only on release (onValueChangeFinished) or tap; tick haptic if "Vibration à chaque cran" on.
- Locks: M none; Av shutter; Tv aperture; P shutter+aperture; B shutter shows "Bulb" (locked); scene/A+/CA/movie: shutter+aperture+ISO; C1–C3/unknown/absent: none.
- Locked slider: disabled, reduced opacity, "Auto" overlay + hint line; thumb follows current value.
- ISO Auto = value 0x00 as first notch when available; on Auto the card shows "Auto" but stays usable.
- Focus: buttons Proche / AF / Loin; step Moyen=2 / Grand=3 (setting, default Grand); AF disabled when lens MF (0xD108 == 3).
- Timer: mini-wheel per spec; delay persisted; counting runs on the phone that shoots; changing delay during countdown cancels it.
- Dev mode: only when no real camera connected; banner « Mode développeur — aucune commande n'est envoyée »; commands logged « [dev] … ».
- RemoteState/protocol stays backward compatible (new fields with defaults).
- Version 0.4.0 (versionCode 4).

### Task 1: Bluetooth discovery + pairing
Relay: "Rendre visible (2 min)" button (ACTION_REQUEST_DISCOVERABLE 120 s, BLUETOOTH_ADVERTISE) in the relay Bluetooth section with hint « Sur la télécommande, touche Rechercher ». Remote: lists « Appareils appairés » and « Appareils à proximité » (button « Rechercher »: startDiscovery, ACTION_FOUND/ACTION_DISCOVERY_FINISHED receiver, BLUETOOTH_SCAN, cancel on leaving the screen); tapping an unpaired device → createBond() → connect on BOND_BONDED (ACTION_BOND_STATE_CHANGED); unnamed devices ignored. Pure list-merge/dedupe logic (`BluetoothDeviceList`) with JVM tests (by address, bonded first, sorted by name).

### Task 2: core — shooting mode & focus mode
`CanonProp.SHOOTING_MODE = 0xD105`, `CanonProp.FOCUS_MODE = 0xD108`. `CameraState` gains `shootingMode: Int? = null`, `focusMode: Int? = null` (applied from PropValueChanged like settings). `enum class ExposureMode { P, TV, AV, M, BULB, SCENE, CUSTOM, UNKNOWN }` + `fun exposureModeOf(code: Int?): ExposureMode` (0 P, 1 Tv, 2 Av, 3 M, 4 B; 7/0x10/0x11 CUSTOM (C1–C3); 8 and 0x09,0x0A..0x0F,0x13,0x14,0x15,0x16,0x17,0x18,0x19 SCENE; null/else UNKNOWN) and `fun modeLabel(code: Int?): String?` ("P","Tv","Av","M","B","C1","C2","C3","A+","Scène", null if absent, hex if unknown). `data class ExposureLocks(shutter, aperture, iso)` + `fun locksFor(mode: ExposureMode)`. `fun isManualFocus(focusMode: Int?) = focusMode == 3`. RemoteState mirrors the two new fields (defaults null). Tests for all mappings + event application + RemoteState round-trip + old JSON without fields still decodes.

### Task 3: core — ControlsModel v2
Replace tiles model with: `SliderModel(setting, title, valueLabel, options: List<Pair<Int,String>>, index: Int, majorIndices: Set<Int>, enabled, locked, lockHint: String?, autoSelected: Boolean)` for SHUTTER, APERTURE, ISO (order Vitesse, Ouverture, ISO); WB keeps a `ChoiceModel` (picker); `FocusModel(afEnabled, manualStepsEnabled, lensLabel: "AF"|"MF"|null, afHint)`; header `modeLabel`; `shutterEnabled`, `liveView*` as before. `CanonValues.isMajor(prop, value)`: full stops (shutter: 30",15",8",4",2",1",0"5,1/4,1/8,1/15,1/30,1/60,1/125,1/250,1/500,1/1000,1/2000,1/4000,1/8000; aperture: 1.0,1.4,2.0,2.8,4.0,5.6,8.0,11,16,22,32,45,64,91; ISO: Auto,100,200,400,…,51200). Hints: shutter « Molette du boîtier sur M ou Tv pour régler », aperture « Molette du boîtier sur M ou Av pour régler », ISO (scene) « Mode scène : ISO automatique ». Bulb: shutter locked, valueLabel "Bulb". Disconnected → everything disabled, "—". Keep existing tests' intent; update tests. CameraScreen adapted minimally to compile (full UI in Task 5).

### Task 4: app — preferences + timer state machine
AppSettings/UiPreferences add: `shutterHaptic=true`, `shutterSound=false`, `tickHaptic=true`, `focusStep=LARGE` (`FocusStepSize { MEDIUM(2), LARGE(3) }`), `timerDelay=0` (0|2|10), `rememberRelayLinks=true`, `relayLinks` (set of WIFI_LOCAL/HOTSPOT/BLUETOOTH, default {WIFI_LOCAL}), `devMode=false`. Pure `class ShutterTimer(scope, clock/delay injectable)` with `state: StateFlow<TimerState>` (Idle | Counting(remaining)) and `press(delay, fire: suspend () -> Unit)`: Idle+0 → fire now; Idle+d → count down d..1 then fire; Counting → cancel. `onDelayChanged()` cancels a running count. JVM tests (virtual time).

### Task 5: app — Appareil v2 UI + settings UI + haptics/sound + remember links
Header (Basique/Avancé segmented, mode chip, status chip); Basique per spec (3 slider cards with M3 Slider steps, Auto overlay, focus card, WB/Live view row, shutter + timer mini-wheel per mockup incl. all behaviours); Avancé card « Timelapse — bientôt ». Haptics: tick on each notch (HapticFeedbackType / View.performHapticFeedback(CLOCK_TICK)), shutter (CONFIRM); sound MediaActionSound SHUTTER_CLICK. Settings: Prise de vue (3 switches + pas de mise au point), Connexion (mémoriser les liaisons), Diagnostic (Mode développeur). Relay links restored from settings when remember is on.

### Task 6: app — developer mode
`DevCameraController : CameraController` (in :app, KDoc: test tool) with realistic 90D lists, simulated mode/AF-MF/live view (generated test image), every command logged « [dev] … » and applied locally. Active only when devMode && no real camera connected; banner + panel (mode M/Av/Tv/P/B/A+, AF/MF, live view test image). JVM tests for the controller's pure behaviour where feasible.
